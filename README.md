# Countries Data Analysis EDA 🌍

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a dataset containing information about 194 countries and 64 different variables.

## Dataset Information
- Total Rows: 194
- Total Columns: 64

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data Loading
- Data Inspection
- Data Cleaning
- Missing Value Analysis
- Statistical Summary
- Region-wise Analysis
- Data Visualization
- Correlation Analysis

## Key Findings
- The dataset contains information about 194 countries.
- Countries are distributed across different regions and continents.
- Population and GDP show significant differences between countries.
- Life expectancy, internet access, and health-related indicators provide useful insights.
- Environmental and energy indicators help analyze global sustainability.

## Project Files
- `countries-ipynb.ipynb` - Complete EDA project notebook

## Conclusion
This Exploratory Data Analysis project provides useful insights into global country-level data using Python data analysis and visualization libraries.
